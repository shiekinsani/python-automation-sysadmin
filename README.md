# System Health Check Automation (Linux/WSL)

### 📋 Description
A Python-based automation script designed for Sysadmins to monitor system health. It tracks CPU and RAM usage in real-time and logs the data for monitoring purposes.

### 🚀 Features
- Monitors CPU usage percentage.
- Monitors RAM usage (Available vs Used).
- Designed to run on Linux/WSL environments.
- Implemented using Python `psutil` library.

### 🛠️ Tech Stack
- **Language:** Python 3
- **Environment:** Ubuntu (WSL)
- **Version Control:** Git & GitHub
